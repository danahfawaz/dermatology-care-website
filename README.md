# Dermatology Care Website

A web technologies project developed using HTML, CSS, PHP, and MySQL. The website demonstrates a simple dermatology clinic system where users can view doctors, book appointments, and manage appointment records.

## Features

- Dermatology clinic homepage
- Doctors information page
- Appointment booking form
- Store appointment records in a MySQL database
- View previous appointments
- Edit appointment information
- Delete appointments
- Login and sign-up interface
- Basic form validation

## Technologies Used

- HTML
- CSS
- PHP
- MySQL / MariaDB
- XAMPP
- phpMyAdmin

How to Run the Project
Download or clone the repository.
Move the project folder into the XAMPP htdocs folder.
Start Apache and MySQL from the XAMPP Control Panel.
Open phpMyAdmin.

Create a database named:
dermatology_db

Import the dermatology_db.sql file.

Open the project through:
http://localhost/dermatology-care-website/
